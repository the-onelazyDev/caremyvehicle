### 2. How to Outgrow CarDekho, CarWale, 91Wheels & Cars24
1. **Zero-Spam On-Road Price Calculator**: Deliver transparent city prices without asking for mobile number/OTP.
2. **Variant Decider Matrix**: Tell the user mathematically which variant gives maximum value for money.
3. **Full Lifecycle Vehicle Care**: Cover the post-purchase experience (5-year scheduled service costs, spare parts pricing, diagnostic troubleshooting).
4. **Dealer Quote Auditor**: AI scanner that flags inflated dealer insurance, illegal handling charges, and overpriced accessories from dealer quotation sheets.
